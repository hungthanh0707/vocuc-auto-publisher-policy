# VoCuc Auto Publisher policy site

Triển khai nhanh bằng GitHub Pages:

1. Tạo repository public, ví dụ `vocuc-auto-publisher-policy`.
2. Upload toàn bộ nội dung package này vào root repo.
3. GitHub → Settings → Pages.
4. Source: `Deploy from a branch`.
5. Branch: `main`, folder: `/ (root)`.
6. Chờ GitHub cấp URL HTTPS.

Nếu GitHub username là `YOURNAME`, dùng:
- Miền ứng dụng: `YOURNAME.github.io`
- Privacy: `https://YOURNAME.github.io/vocuc-auto-publisher-policy/privacy/`
- Terms: `https://YOURNAME.github.io/vocuc-auto-publisher-policy/terms/`
- Data deletion: `https://YOURNAME.github.io/vocuc-auto-publisher-policy/data-deletion/`
